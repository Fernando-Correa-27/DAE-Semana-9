# Créditos — Cartelera de Cine

## Fuentes de Datos

### Películas y datos cinematográficos

Todos los datos de películas (títulos, sinopsis, calificaciones, géneros, fechas de estreno) fueron obtenidos o inspirados en información pública de:

- **The Movie Database (TMDB)** — https://www.themoviedb.org/
  - API: themoviedb.org
  - Datos consultados: películas populares, próximas estrenos, metadatos
  - Licencia: CC BY-NC 4.0

### Imágenes

Los pósters de películas son creaciones originales en formato SVG generadas localmente como placeholder artístico. Las imágenes reales de pósters provienen de:

- **TMDB Image API** — image.tmdb.org
  - Los pósters descargados se convirtieron a formato WebP para optimización
  - Todas las URLs externas fueron convertidas a archivos locales en `src/assets/`

## API y Servicios de Terceros

### The Movie Database (TMDB)

Este proyecto utiliza información de TMDB. TMDB es una comunidad de fans que recopila información sobre películas, series de TV, actores y personajes.

- Sitio web: https://www.themoviedb.org/
- API: https://www.themoviedb.org/api
- Términos de uso: https://www.themoviedb.org/about/tou/the-movie-database
- Licencia de datos: Creative Commons Attribution-NonCommercial 4.0 International

### Fuentes adicionales

- Información de estrenos de cine obtenida de fuentes públicas:
  - Box Office Mojo — https://www.boxofficemojo.com/
  - Deadline — https://deadline.com/
